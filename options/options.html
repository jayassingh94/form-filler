AI matching

Used only to work out which profile field each form field asks for. It never receives your values or documents. How it works

The free Form Filler AI isn't set up in this version, so offline matching is used. Choose "my own key" to use AI.

Backup & data

Move your details to another computer, or erase everything.

Export backup

One file with all profiles, documents and settings, still encrypted with your current PIN.

Import backup

Replaces everything stored now. Unlock afterwards with the PIN used when the backup was made.

Delete all data

Permanently erases all profiles, documents, the API key and your PIN from this browser. This cannot be undone.
