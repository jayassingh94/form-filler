Form Filler
Fill a PDF Privacy

Changes save automatically and are encrypted. Fill only what you want; empty fields are skipped. Dates are stored as day/month/year and converted to each form's format.

Custom fields

Anything else a form may ask for (e.g. "Employee ID", "Registration number"). The field name is shared with the AI so it can recognise the field; the value never is.

Just trying it out? and use it on test/sample-form.html.

Document Locker

Photo, signature, marksheets, certificates… Stored encrypted in this browser. When you click Fill this form, a 📎 Pick from locker button appears next to every upload field on the page.

AI field matching (Google Gemini)

Gemini is used only to work out which of your profile keys each form field asks for. It receives field labels, placeholders and dropdown option texts from the page, plus the list of generic profile key names. It never receives your profile values or documents. Without a key, a simpler offline keyword matcher is used.

Sites with access

Form Filler asks for access to a site only when you click Fill this form there. You can remove access at any time.

Export backup

Downloads one file with all profiles, documents and settings. It stays encrypted with your current PIN, so you'll need that PIN to open it after importing. Keep it somewhere safe.

Import backup

Replaces everything currently stored with the backup's contents. Afterwards, unlock with the PIN that was in use when the backup was made.

Delete all data

Permanently erases all profiles, documents, the API key and your PIN from this browser. This cannot be undone. Type DELETE to confirm.
